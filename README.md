# PsicoSim IA · Simulador Clínico de Pacientes

> **Simulador de pacientes con Inteligencia Artificial para el entrenamiento de entrevistas clínicas en estudiantes de Psicología.**

🌐 **Enlace público para usar la aplicación:**  
👉 **[https://pmcruz-crypto.github.io/PROYECTO/](https://pmcruz-crypto.github.io/PROYECTO/)**  
*(Funciona directamente en navegadores de computador y celulares sin instalar nada).*

---

## 1. El Problema
Los estudiantes de Psicología que se preparan para realizar entrevistas clínicas suelen tener dificultades para formular preguntas abiertas, explorar síntomas y establecer una comunicación empática. Aprender únicamente mediante libros y clases teóricas ofrece pocas oportunidades para practicar conversaciones clínicas. Además, los primeros ejercicios con pacientes reales generan inseguridad y temor a equivocarse, mientras que los juegos de roles con compañeros requieren coordinación y no siempre permiten simular situaciones realistas.

## 2. El Usuario
Estudiantes de Psicología de pregrado que cursen asignaturas de evaluación psicológica o se preparen para sus primeras prácticas clínicas supervisadas.

## 3. Funciones Implementadas
1. **Buscar un caso clínico:** Selección de pacientes virtuales con fichas diagnósticas basadas en el DSM-5 y CIE-10 (Ansiedad Generalizada, Depresión Mayor, TOC, Fobia Social). Filtros por categoría y nivel de dificultad.
2. **Realizar una entrevista simulada:** Chat interactivo para explorar el motivo de consulta, emociones, síntomas y situación del paciente en tiempo real. Soporte para dictado por voz y cuaderno de campo del terapeuta.
3. **Interactuar con el paciente virtual:** Respuestas generadas por IA coherentes con la patología seleccionada, lectura de comunicación no verbal (expresiones, latencia y signos vegetativos) y síntesis de voz del paciente.
4. **Consultar retroalimentación (Debriefing):** Al finalizar la sesión, el estudiante recibe un informe pedagógico con métricas sobre preguntas abiertas vs. cerradas, nivel de empatía, alianza terapéutica y detección de preguntas inductivas o sesgadas con sugerencias de reformulación.
5. **Panel de Progreso Académico:** Registro de casos completados, horas acumuladas y evolución de competencias clínicas.

## 4. Lo que no hace
La aplicación no atiende a pacientes reales, no realiza diagnósticos clínicos reales ni sustituye la formación universitaria o la supervisión de un profesional. Tampoco asigna calificaciones oficiales, ya que la evaluación corresponde al docente supervisor.
